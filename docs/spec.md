# WeatherStation

WeatherStation — настольное WPF-приложение для Windows для наблюдения за погодой в выбранных городах. Оно объединяет текущую погоду, прогноз и личный журнал наблюдений. Пользователь может узнать, какая погода ожидается, посмотреть, как менялись условия в городе, и получать предупреждения по интересующим его показателям.

## Как работает приложение

Пользователь выбирает город и видит текущую погоду и прогноз Open-Meteo. Текущие показатели можно сохранить в журнал. Запись можно добавить и вручную, например внести температуру с уличного термометра. У каждой записи виден источник, чтобы при просмотре истории можно было отличить собственный замер от данных сервиса.

Журнал хранится на компьютере. Без интернета пользователь может работать с сохранёнными наблюдениями и добавлять новые вручную. Подключение требуется для получения свежей погоды и загрузки городов из сети.

## Основные функции

| Раздел | Возможности пользователя |
| --- | --- |
| Погода | Посмотреть текущие показатели и прогноз для выбранного города, обновить данные вручную, увидеть время последнего обновления и сохранить текущую погоду как наблюдение. |
| Города | Найти город в локальном справочнике, выбрать его для просмотра погоды и пополнить справочник из списка городов России в Википедии. При повторной загрузке уже добавленные города пропускаются. |
| Журнал наблюдений | Добавлять, редактировать и удалять записи. В подробностях видны город, дата и время, погодные показатели, источник и заметка. Записи можно искать, сортировать, группировать и фильтровать одновременно по нескольким полям. Для выборки видны число записей и средняя температура. |
| Датчики | Выбрать, какие показатели отслеживать в каждом городе. Датчик в WeatherStation — это виртуальный датчик одного показателя, например температуры, влажности или скорости ветра. |
| Предупреждения | Задать порог для отслеживаемого показателя и увидеть, какое наблюдение вызвало предупреждение. Например, пользователь может следить за заморозками в одном городе и за сильным ветром в другом. |
| Настройки | Переключить светлую и тёмную тему, включить или выключить периодическое обновление погоды, выбрать папку для экспорта. Настройки сохраняются между запусками. |

## Обмен данными

Наблюдения можно экспортировать в JSON и импортировать из файла, например для переноса журнала на другой компьютер. После импорта пользователь видит, сколько записей добавлено, сколько пропущено как дубли и сколько содержало ошибки.

Во время загрузки или импорта приложение показывает ход операции и позволяет её отменить. Если получение погоды не удалось, пользователь видит причину ошибки и может продолжить работу с локальным журналом.
