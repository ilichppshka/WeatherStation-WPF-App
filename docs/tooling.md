# Инструменты WeatherStation

Статус «Выбрано» означает, что инструмент включён в план и будет подключён при реализации соответствующей функции. Границы приложения описаны в [architecture.md](architecture.md).

## Приложение и разработка

| Инструмент | Назначение | Статус |
| --- | --- | --- |
| C#, .NET 10, WPF | Настольное приложение для Windows. Версия SDK закреплена в [global.json](../global.json). | Подключено |
| .NET Generic Host, Microsoft.Extensions.DependencyInjection | Запуск приложения, управление жизненным циклом и регистрация зависимостей. | Подключено |
| CommunityToolkit.Mvvm | ViewModel, наблюдаемые свойства, команды и валидация. | Выбрано |
| WPF UI (`lepoco`) | Готовые элементы интерфейса и навигация в стиле Windows 11. | Выбрано |
| SQLite, EF Core | Локальное хранение данных. EF Core выполняет запросы, сохранение и миграции схемы. | Выбрано |
| HttpClient, Open-Meteo | Запросы текущей погоды и прогноза. | Выбрано |
| Newtonsoft.Json | Работа с JSON, в том числе импорт и экспорт журнала. | Выбрано |
| HtmlAgilityPack, XPath | Извлечение данных из HTML для пополнения справочника городов. | Выбрано |
| LiveCharts2 | Графики погоды и истории наблюдений. | Выбрано для этапа с графиками |
| Visual Studio Community | Разработка, запуск и отладка WPF на Windows. | Выбрано |

## Проверка кода

| Инструмент | Назначение | Статус |
| --- | --- | --- |
| `dotnet format style` | Проверяет правила стиля C# перед сборкой. Флаг `--verify-no-changes` выводит нарушения без правки исходников. | В правилах агента |
| Анализаторы .NET | Статический анализ C# во время сборки. | Включены в SDK |
| xUnit v3, Microsoft.Testing.Platform | Написание и запуск автоматических тестов через `dotnet test`. | Подключено |
| Xunit.StaFact | Атрибут `[WpfFact]` для тестов, которым нужен диспетчер WPF. | Подключено |
| NSubstitute | Подмена зависимостей в тестах, например клиента погоды. | Выбрано |
| Git, GitHub, GitHub Actions | История изменений и pull request. [CI](../.github/workflows/ci.yml) собирает решение и запускает тесты на Windows. | Настроено |

Порядок проверки после изменений кода описан в [AGENTS.md](../AGENTS.md).

## Работа с агентом

| Инструмент | Назначение | Статус |
| --- | --- | --- |
| Codex, `AGENTS.md` | Работа агента в репозитории. `AGENTS.md` задаёт правила и направляет к документации проекта. | Настроено |
| OpenSpec | Требования и задачи для конкретного изменения, реализация по плану и архивирование. | Настроено |
| Ponytail | Помогает держать изменения небольшими и проверять их на ревью. | Установлено |
| Grill with Docs | Помогает уточнять неоднозначные требования и фиксировать термины и решения. | Установлено |
| `modern-csharp-coding-standards`, `dotnet-wpf-modern`, `mvvm-toolkit`, `dotnet-xunit` | Справочные материалы для агента по C#, WPF, MVVM и xUnit. | Установлены |
